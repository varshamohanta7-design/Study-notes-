1. Web Browser & Internet Fundamentals

• Frameset: Special HTML structure that divides a single browser window into multiple sections so different web documents can be displayed simultaneously.

• HTML: Stands for HyperText Markup Language. Standard language used to structure & create web pages.

• URL: Uniform Resource Locator — The unique web address of a web page on the internet.

• Hyperlink: A clickable text, image, or button that opens another web page or jumps to a specific location within the same page.

• Browser Cookies: Small text data files created by a web server and stored locally by the browser to remember user preferences, sessions & login states.

• SEO (Search Engine Optimization): Process of optimizing website content to improve its visibility & rank in search engine results.

Exam Tip: Web Basics

👉 Cookies are stored on the CLIENT side (browser), but originally sent by the SERVER!

👉 Don't confuse URL (address) with HTTP (protocol)!

Essential Network Connecting Devices:
  • Router: Connects DIFFERENT networks together. Forwards data packets using IP routing tables.
  • Switch: Connects devices within the SAME LAN. Intelligent device — sends data only to the specific intended device (using MAC address).
  • Bridge: Connects multiple LAN segments together into one logical network.
  • NIC: Network Interface Card — Hardware expansion card/chip connecting a computer directly to a network cable or wireless signal.
  • Proxy Server: Intermediary server that controls network access, improves security, caches data & can act as a Firewall.

High-Yield Internet Protocols

• HTTP: HyperText Transfer Protocol — Application Layer Protocol used for requesting & transmitting web pages.

• HTTPS: HyperText Transfer Protocol Secure — Encrypted version of HTTP using SSL/TLS.

• SMTP: Simple Mail Transfer Protocol — Used for SENDING / PUSHING emails to mail servers.

• POP3: Post Office Protocol v3 — Downloads email locally to device & deletes from server. Best for single device access.

• IMAP: Internet Message Access Protocol — Synchronizes emails across MULTIPLE devices simultaneously. Preferred for modern access.

• DHCP: Dynamic Host Configuration Protocol — Automatically assigns IP addresses to devices on a network.

📌 IP Address Comparison (IPv4 vs IPv6)
IPv4:
  • 32-bit address length
  • 4 numeric octets
  • E.g. 192.168.1.1
IPv6:
  • 128-bit address length
  • Hexadecimal groups
  • Huge address space

3. Email Concepts & Computer Memory

📧 Email Features & Terminology
  • Subject Missing: Email client prompts/asks confirmation before sending email without a subject line.
  • CC (Carbon Copy): Secondary recipient visible to all other recipients.
  • Safe Sender List: Whitelist that prevents wanted emails from going to Spam.
  • Recall Message: Feature that attempts to retrieve/unsend an email sent accidentally.
  • Out of Office: Automated reply sent when absent or on vacation.
🛡️ Security & Mail Protocols
  • Digital Signature: Authenticates identity of sender & ensures integrity.
  • Email Encryption: Protects content from unauthorized interception.
  • MIME: Multipurpose Internet Mail Extensions — Allows non-text attachments (images, audio, videos).
  • Spam: Unsolicited bulk commercial email.
  • Phishing: Fraudulent email attempt to steal sensitive user info (passwords, banking).

Computer Memory & Storage Pyramid

• Primary Memory: Direct CPU access.
  — RAM (Random Access Memory): Volatile (data lost on power off). Read & Write.
  — ROM (Read Only Memory): Non-Volatile (retains data permanently). Contains BIOS.
  — EEPROM: Electrically Erasable Programmable Read Only Memory.

• Cache Memory: Extremely fast, high-speed buffer.
  — Works directly between CPU and RAM to reduce data access latency!

• Secondary Memory: Permanent external storage (Non-volatile). E.g., HDD (Hard Disk Drive), SSD (Solid State Drive), CD/DVD, USB Flash Drives.

4. Computer Fundamentals, OS & I/O Devices

• Booting: Process of loading Operating System from secondary disk into RAM upon startup.

• Reboot: Restarting an already powered-on computer system.

• GUI vs CLI: Graphical User Interface (Windows, icons) vs Command Line Interface (DOS, prompt).

• Information: Processed & structured data meaningful to users.

• Computer Speed: Measured by Clock Speed (GHz).

• Pixel: Smallest single dot or addressable element on a display screen.

• Data Redundancy: Unnecessary storing of the exact same data multiple times.

• Segmentation: Division of computer memory space into logical segments.

• Barcode: Optical machine-readable code storing data using parallel bars of varying widths.

• Processor Architecture: Contains Control Unit (CU) + Arithmetic Logic Unit (ALU). Microprocessors consist of millions of Transistors!

• Operating System Functions: Hardware-Application interface, Resource Management, System services ➔ Exam Answer: All of the Above.

⚠️ Frequently Confused Points (Avoid Negative Marking!)

❌ POP3 vs IMAP

• POP3: Downloads email to ONE single device & deletes from server.
• IMAP: Keeps emails on server & SYNCS across MULTIPLE devices.

❌ Ctrl + N vs Ctrl + M (PowerPoint)

• Ctrl + N: Opens a NEW Presentation File.
• Ctrl + M: Inserts a NEW SLIDE in the current presentation!

❌ Router vs Switch

• Switch: Operates inside the SAME LAN.
• Router: Connects DIFFERENT, separate networks together.

❌ RAM vs ROM

• RAM: Volatile (temporary), read & write.
• ROM: Non-volatile (permanent), read-only.

📝 Practice Exam MCQs (Click to Reveal Topper Explanation)

Q1. Which device connects different networks together and forwards data packets using IP routing?

✅ Answer: Router — Switch connects devices within the same LAN; Router connects separate networks.

Q2. What is the shortcut key to insert a NEW SLIDE in Microsoft PowerPoint?

✅ Answer: Ctrl + M — Common trap: Ctrl+N creates a new file, Ctrl+M creates a new slide.

Q3. Which OSI layer handles end-to-end user web protocols like HTTP and SMTP?

✅ Answer: Layer 7 (Application Layer) — Remember mnemonic: 'Away' = Application Layer.
